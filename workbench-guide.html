阶段 0需求拆解 · 先问清，再动手◆ 模块清单 + 字段清单 + 业务规则清单
① 锁定身份与工作流
职业（党校教授）+ 全部业务（备课/上课/科研/试讲/听评课/写作/习课）逐个列成模块
② 逐条收集业务口径
计费（上饶480｜南昌400/600/800｜首次科级+200｜外出2课时400等六档）、试讲规则、微课5步、统计口径
③ 问清底线偏好
视觉风格、数据实时保存可溯源、课程可从专题库下拉、提示词必须深度分析不编造
阶段 1架构定案 · 一次定死，别来回改◆ 单文件 index.html
① 单文件原生 HTML/CSS/JS
零框架、零构建，一个 index.html 全包；三方库仅白名单 CDN（字体走国内镜像）
② 数据存 localStorage
key 定死为 应用名_v2 永不更改；升级加后缀迁移，改 key = 数据全丢
③ Hash 路由 + 视觉
#/prep、#/class 免服务器配置；米白/象牙白/深墨绿/灰棕+酒红，禁科技蓝/卡通/OA
为省事先写功能不写架构 → 后面加模块四处打补丁，路由乱成一团
阶段 2数据安全层 · 最先搭，生命线◆ 三级备份 + 云同步 + 结构保障
① 三级防丢
主数据 KEY + 影子备份 KEY_shadow + 每日快照（保留14天），主数据损坏自动回退
② Gitee 双向同步
打开拉取/保存推送；_cloudReady 标志——初始拉取完成前禁止推送
③ ensureSchema 统一补结构
本地旧数据/云端/导入备份后必补数组；缺字段 → 渲染崩溃、页面切换中断
④ 防卡防覆盖
拉取加 8 秒超时；云端结构异常不覆盖本地；本地更新更多时不被旧备份顶掉
自动推送跑在初始拉取前 → 种子数据覆盖云端好数据（用户最恐惧的事）；拉取无超时 → 打开卡顿
阶段 3UI 框架 · 导航骨架◆ 可导航的空壳
① MODULES 注册
name / vol（卷标）/ icon 三个字段定义全部路由
② renderNav()
左侧分组导航（案头 / 书卷·七录 / 工具），带未完成计数徽标
③ render() 分发
switch(r) 调对应渲染函数 + 顶部栏显示模块名/日期
新增模块四步缺一不可（MODULES + render函数 + switch case + 导航组）——少一步点导航就回首页
阶段 4功能开发 · 按此顺序，每步做完立即保存◆ 全模块可用工作台
① 案头首页
今日课时/课时费/待办/进行中项目/灵感札记，一屏总览
② 上课
校内外两表 + 计费口径硬编码 + 月度追溯 + 区间汇总，统计全部实时计算
③ 备课/科研
项目卡片 + 自动拆步骤排日期 + 版本历史（未完成可回退，完成留最终版）
④ 试讲/听评课
流程勾选框每次新建必须重置，不记住上次状态
⑤ 随手记
自然语言输入 → 正则解析 → 自动归类到对应模块 → 用户点确认才入库
⑥ 灵感库 + 素材
灵感可设为"备课指导"；素材每日推送10条不同来源，确认有用才存云端
⑦ 豆包开工入口
按课程/模块生成提示词 → 复制 → 打开 doubao.com/chat；纯前端不做真实AI调用
⑧ 写作/范文库/好课库
导入文件 → 自动识别字段 → 深度分析 → 技法级提示词 → 豆包直达
讲稿与课件要成对联动（pairId 双向关联）——只建不连，两者各算各的；Excel 导入必须剔除"合计"行否则费用翻倍
阶段 5测试 · 用"会失败"的动作验证◆ 全路由渲染通过
① 语法闸
提取 script 后 node --check，括号/引号配平
② DOM shim 全路由测试
Node vm 模拟浏览器渲染每个模块，每功能至少3用例（正常/边界/异常）
③ 旧数据兼容回归
模拟缺新字段的旧版数据加载 → 不崩溃；关键统计（课时费/学时/人次）抽样重算核对
阶段 6部署 · 国内可访问（电脑端）◆ 公网链接
① 主站 GitHub Pages
deploy_to_github.sh 上传 index.html；域名 username.github.io/repo/ 返回 text/html 正确渲染
② 备份 Gitee
Contents API PUT（先取 SHA），存 index.html + backup/数据.json，双端容灾
③ 线上验证
curl 加 ?cb=时间戳 绕 CDN 缓存，grep 关键代码串确认已更新
手机端死路勿再试：Vercel（Google 登录被墙）、Gitee Pages（官方下线）、腾讯云COS（iPhone 打不开）、jsDelivr（显示源码）、Surge/EdgeOne（不稳/限时）。手机端放弃，专注 Mac
阶段 7数据迁移与维护 · 长期不丢数据◆ 可随时换站/升级的持久数据
① 换站迁移
旧站「数据安全中心」导出 JSON → 新站导入备份（自动补结构），不丢一条
② 升级规则
localStorage key 永不改、新增字段靠 ensureSchema 兼容旧数据、发布后提醒 Cmd+Shift+R 强刷
③ 交付三件套
index.html 源文件 + 公网链接 + 部署说明（令牌/仓库/备份路径），完整交代
全流程速查避坑清单：① 新模块必须 MODULES+render+switch+导航四步齐 → ② 云推送必须在初始拉取后（_cloudReady）→ ③ localStorage key 定死永不改 → ④ 讲稿课件用 pairId 双向联动 → ⑤ 试讲/听评课勾选框每次重置 → ⑥ Excel 导入先剔合计行 → ⑦ 数据源统一走 ensureSchema 补结构 → ⑧ 部署只用 GitHub Pages 主站 + Gitee 备份，手机端不折腾。

三句心法

① 数据安全层最先搭——一切功能都长在数据上，三级备份 + 云同步 + 结构保障必须先于功能存在。
② 每个新模块四步闭环——MODULES 注册、渲染函数、路由分发、导航入口，缺一步就"加了但点不到"。
③ 部署只认 GitHub Pages 主站 + Gitee 备份——国内其他方案（Vercel / COS / jsDelivr / EdgeOne）全部踩过坑，别再走。
